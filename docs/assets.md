# Ресурсы и брендовые файлы

| Ресурс | Расположение | Использование |
|---|---|---|
| Логотип и его SVG-path `#logoPath` | `assets/brand/logo.svg` | favicon, Open Graph, внешняя SVG-ссылка для знаков и геометрия Canvas через `Path2D` |
| Дизайн-токены и правила бренда | `brand-spec.md` | цвет, типографика, анимация, правила применения логотипа |
| SVG сцены и узлов | генерируются Canvas/UI-кодом | зависят от размера окна, состояния и анимации; отдельных исходных файлов не имеют |
| Геометрия сцены (числа) | `assets/generated/scene-data.js` из `assets/js/scene/geometry.js` | клин, спина, узлы, облако точек, сигилы скиллов; Path2D из них собирает `index.html` |
| Шрифты | Google Fonts ссылки в `index.html` | загружаются удалённо; локальные копии в репозитории не хранятся |

Исходный SVG один: и legacy-лендинг, и Mini App ссылаются на `assets/brand/logo.svg`.
Сцена получает `d` того же `#logoPath` запросом файла и создаёт `Path2D`; путь больше не
дублируется внутри HTML. При замене формы нужно обновить этот SVG и сохранить `viewBox`
`0 0 499 499` и идентификатор `logoPath`.

`Dockerfile` копирует каталог `assets/` целиком в web-образ. Локальный fixture-сервер
раздаёт SVG с `image/svg+xml`. Для проверки UI важно открывать страницу через HTTP(S), а не
`file://`: загрузка отдельного SVG через `fetch` ограничивается политикой браузера.

Перед добавлением больших растровых файлов, шрифтов или видео сначала задать владельца,
исходник, лицензию, размер/формат и кэширование.

## Сгенерированный ресурс: геометрия сцены

**CONTRADICTION** — наблюдаемое / документированное / принятое: раньше здесь было «такого
asset pipeline в проекте нет»; теперь есть один сгенерированный ресурс, описанный ниже.
Других сгенерированных ресурсов нет.

| Что | Значение |
|---|---|
| Владелец | фронтенд Mini App (`index.html`) |
| Исходник | `assets/js/scene/geometry.js` (алгоритм и сиды) + `TIERS`, `BRANCHES` из `economy.js` |
| Генерация | `npm run build:scene` → `tools/build-scene-data.mjs`: пишет `assets/generated/scene-data.js` и выставляет `?v=<sha256 содержимого, 8 символов>` в `index.html`. Файл лежит в Git; `tests/scene-data.test.mjs` перегенерирует его и падает, если копия устарела |
| Лицензия | собственный код проекта, внешних данных нет |
| Размер и формат | ~33,7 КБ (~10 КБ gzip): скрипт `window.RIZZOMA_SCENE = {…}`, координаты округлены до 1e-6: расхождения движков в последнем бите `Math.sin/cos` до них не доходят. Совпадение Node и Chromium проверено, JavaScriptCore (iOS) не проверялся |
| Кэширование | nginx, `location ^~ /assets/generated/`: вход по сессии (`auth_request`), ответы 200/304 — `Cache-Control: private, max-age=31536000, immutable`, остальные — `no-store`; gzip. Новая версия приходит новым адресом (`?v=`). Общий кэш (CDN/прокси) не допускается: вход закрытый |
| Содержимое | только геометрия, одинаковая для всех пользователей и контуров: ни `betaOpen`, ни цен, ни идентификаторов, ни адресов — проверяет `tests/scene-data.test.mjs` |
| Запасной путь | нет файла, ошибка загрузки или `version` не совпадает с входами из текущего `economy.js` — страница считает те же числа модулем `geometry.js`; e2e `tests/e2e/scene.spec.mjs` сверяет оба пути до пикселя |

Замер (Chromium 141, 390×844, dpr 2, замедление CPU через CDP, медианы; 2026-09-29):

| CPU | Сборка сцены до / после | Разбор ресурса | Первый кадр до / после, холодный и повторный запуск | FCP до / после, холодный и повторный |
|---|---|---|---|---|
| ×1 | 3,1 / 1,2 мс | ~0,3 мс | 380 / 396 и 385 / 400 мс | 420 / 444 и 428 / 448 мс |
| ×4 | 12,9 / 6,0 мс | ~1,2 мс | 563 / 566 и 588 / 592 мс | 696 / 672 и 716 / 700 мс |
| ×6 | 16,9 / 7,5 мс | ~2 мс | 693 / 690 и 715 / 669 мс | 868 / 860 и 884 / 836 мс |

Работа сцены на главном потоке сократилась в 2–2,5 раза, но в абсолютных цифрах это 2–9 мс;
на первом кадре и FCP разница в пределах шума замера (±25 мс, локальный сервер, 15 прогонов).
Самая дорогая часть запуска — растеризация облака `bakeNetwork` (40–65 мс на ×4–×6) — зависит
от `devicePixelRatio` и в ресурс не выносится. Поведение кэша в настоящем Telegram WebView на
телефоне не проверялось; `immutable` поддерживается WebView неодинаково.
