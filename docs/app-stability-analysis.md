# Стабильность базового приложения

Анализ относится к ветке `feat/app` и не включает карту.

## Что устранено в этом изменении

- Пользователь больше не существует только в `Map` процесса: профиль,
  регистрация, first-touch реферал и API-сессия сохраняются в PostgreSQL.
- API отделён от Telegram-бота, имеет ограниченный пул соединений, таймаут
  подключения, liveness/readiness и корректное завершение HTTP/DB.
- Миграции сериализованы advisory lock и проверяются по checksum.
- Ошибки API проходят через один обработчик; в ответе есть `requestId`, а
  body, `initData`, токены и подписи в лог не записываются.
- Запросы регистрации ограничены rate limit, JSON body — 16 KiB, серверные
  HTTP timeout заданы явно.
- Контейнер API не переключается на SQLite или другой локальный fallback при
  недоступности PostgreSQL: readiness становится ошибочным, процесс не стартует.

## Наблюдаемые оставшиеся риски

1. `index.html` содержит около 3 300 строк HTML/CSS/JS и непрерывный Canvas
   `requestAnimationFrame` на вкладке дерева. На слабых телефонах это главный
   кандидат на лаги, а не PostgreSQL.
2. `ResizeObserver` и обработчик `resize` оба вызывают полный пересчёт сцены;
   нужен debounce и замер времени кадра перед изменением поведения.
3. `bot/bot.js` всё ещё хранит платежный журнал, betaOpen и channel engagement
   в памяти. Регистрация уже постоянная, но перечисленные данные переживут
   перезапуск только после отдельной миграции.
4. Frontend подавляет часть сетевых ошибок через `.catch(()=>{})`; пользователю
   доступен offline fallback, но эксплуатации не хватает агрегированной метрики.

## Безопасная последовательность дальнейшего рефакторинга

1. Сначала добавить измерение долгих кадров и числа ошибок без персональных
   данных.
2. Затем вынести Canvas runtime, Telegram adapter и API client из `index.html`
   без изменения DOM/CSS.
3. После стабилизации перенести платежи и engagement в PostgreSQL отдельными
   миграциями.
4. Только после этого менять UI-фреймворк или сборщик: одновременная миграция
   данных и интерфейса затруднит поиск регрессий.
